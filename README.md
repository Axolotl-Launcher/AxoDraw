# AxoDraw · 公开可验证的抽奖

抽奖最怕的就是「凭什么相信你没作弊」。AxoDraw 的思路是：**不让你相信我**——开奖结果由公开的随机信标决定，算法完全公开，任何人随时都能自己复算一遍。

> 🎯 使用地址：**<https://draw.axlmc.org>**（黑白极简风格，无需注册）

## 三步搞定一场抽奖

**1. 发起抽奖**

打开「发起抽奖」页面，填好：

- 抽奖标题；
- 截止时间（按北京时间）；
- 中奖人数；
- 参与值——一行一个，也可以直接上传 `.txt` / `.csv` 文件。

创建时会自动做人机验证，不需要注册账号。

**2. 分享链接**

创建成功后你会拿到三样东西，其中两样可以公开：

- **公开链接** —— 直接发给参与者；
- **抽奖编码**（形如 `AXO-7K4M`）—— 在首页输入即可查询结果；
- **管理链接** —— ⚠️ **只显示一次，请立即保存**。截止前用它修改参与值，截止后 10 分钟，用它点「立即开奖」。

**3. 开奖并核对**

开奖后，中奖名单、随机数、摘要会**永久公开**地挂在页面上。任何人如果怀疑结果，都可以照着页面上的记录自己重算——算出来一定和公布的一致。

## 为什么可以相信它

- **随机数不来自网站**：来自 drand 公开随机信标，每 3 秒全网发布一轮，由多个独立节点共同签名，没有任何一方能提前知道或篡改。
- **用哪一轮随机数由截止时间决定**：跟谁点、什么时候点「开奖」完全无关。
- **算法是死的**：固定算法 + 公开输入 = 唯一结果。中奖名单是「算出来」的，不是谁拍脑袋决定的。
- **全程留痕**：randomness、signature、digest、参与值都在公开页面，随时可查、可复算。

想看逐步图解？网站上的「运行原理」页面讲得很细；也可以直接查示例抽奖 **`AXO-7K4M`**（已开奖）。

## 常见问题

| 问题 | 回答 |
|---|---|
| 需要注册或登录吗？ | 不需要，发起和查询都不需要账号。 |
| 管理链接丢了怎么办？ | 丢了就没人能改参与值、也没人能开奖。结果始终公开，但没人触发就不会产生结果，请务必保存好。 |
| 截止前还能改什么？ | 只能用管理链接改参与值。标题、截止时间、中奖人数创建后不可修改。 |
| 会自动开奖吗？ | 不会。需要持有管理链接的人在截止 10 分钟后手动点「立即开奖」。 |
| 参与值有重复怎么办？ | 创建时可勾选「自动去重」；不勾选的话，重复的每一行都算一张独立票。 |
| 按哪个时区？ | 全部按北京时间（UTC+8）。 |
| 开奖结果还能改吗？ | 不能。开奖写入公开记录后不可修改，参与值在截止后也会锁定。 |
